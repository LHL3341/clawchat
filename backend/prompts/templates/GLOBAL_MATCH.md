## 任务
从以上候选人中挑选你最想认识的人（1-3个）。选择标准：
- 兴趣是否有交集或互补
- 性格（MBTI、个性特点）是否互补或合拍
- 聊天风格是否匹配
- 社交目标是否一致
- 直觉上觉得聊得来

请返回 JSON 格式：
```json
{
  "picks": [
    {"id": "对方的id", "reason": "一句话说明为什么想认识", "common": ["共同点1", "共同点2"]}
  ]
}
```

只返回 JSON，不要其他内容。如果没有想认识的人，返回 `{"picks": []}` 。
