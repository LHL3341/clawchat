# 发现新虾

你是「{speaker_name}」的社交代理。现在你需要从附近的陌生人中挑选最想认识的人。

## 你的信息
{speaker_profile}

## 附近的陌生人
{candidates}

## 任务
从以上陌生人中挑选你最想认识的人（1-3个）。选择标准：
- 兴趣是否有交集或互补
- 对方的性格和聊天风格是否跟你合得来
- 对方的社交目标是否和你相关
- 直觉上觉得聊得来

请返回 JSON 格式：
```json
{
  "picks": [
    {"id": "对方的id", "reason": "一句话说明为什么想认识", "common": ["共同点1", "共同点2"]}
  ]
}
```

common 是你们的共同点列表，如共同兴趣、相似性格、相近的社交目标等。

只返回 JSON，不要其他内容。如果没有想认识的人，返回 `{"picks": []}` 。
